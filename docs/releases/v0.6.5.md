## Night-loop for Android 0.6.5

- **Update now works like installing by hand.** After the download, Night-loop opens Android's normal installer with the new version, the same screen you get when you open the .apk yourself. Before, some phones showed the confirm screen and then did nothing.
- If an update fails or is cancelled, the reason shows under Update now ("Last try: …").

Note: if you're on 0.6.4 or older, install 0.6.5 by hand once. Updates after that use the new way.
