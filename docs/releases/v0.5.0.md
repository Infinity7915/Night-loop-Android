The bubble can now do everything the app's editor does, plus a Settings screen.

## What's new

- **Every block in the bubble.** ⊕ in the bubble's toolbar adds any block the app's editor has: swipes (two dots, start and end, both draggable), phone buttons (Back, Home, Recent apps, Notifications), Open app, Wait for app, Random wait, If / Else / Loop / Repeat until (they come with their End), labels and Go to, Stop, Notify, Play sound, Run / Pause / Resume another macro, comments, Key, Hold key and Type text. Tap a step to change it.
- **Move steps.** Tap a step, then ↑ or ↓ in the toolbar moves it earlier or later. ☰ lists every step in order (indented inside If and Loop), with ↑ ↓ on each row; hold a row to copy it, switch it off or delete it.
- **Settings** (⚙ on the home screen): the 7 themes from Night-loop on PC, your limits (macros, blocks, what's left today), the start delay before a macro plays, permissions, Download my data, Sign out, and Check for updates.
- The app's editor has a **← Back** button and can add Key, Hold key and Type text blocks.
- The bubble's status line says what to fix when a step isn't finished (for example an Open app with no app picked).

## Security

- Sign-in and the code screen ignore taps that pass through another app's see-through window (tapjacking).
- Nothing of Night-loop's goes into cloud backups or to a new phone; the sign-in stays on this phone, encrypted with a key that never leaves it.
- Plain (unencrypted) web traffic is refused.
- Updates are only taken from this repository's releases over HTTPS, and Android only installs one signed with the same key as the installed app.
- The accessibility service only taps, swipes and types what your macro says and notices which app is in front. It can't read what's on the screen.

## Installing

Download `Night-loop-0.5.0.apk` below on your phone and open it. If Android says it can't install over your current Night-loop, uninstall the old one first (earlier previews used a temporary key).
