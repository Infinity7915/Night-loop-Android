## Night-loop for Android 0.5.2

- **Taps no longer stop the macro by mistake.** If Android briefly drops Night-loop's accessibility service or refuses a tap, Night-loop now waits and tries again (up to about a second) before stopping. If it still can't tap, the message says which problem it is.
- **"+ New macro"** on the Home screen, so the button doesn't look like a saved macro.

Some emulators (for example MuMu Player) don't let apps tap the screen. Use a real phone if taps never land.
