## Night-loop for Android 0.8.7

- **"If Roblox is not open" is right after "Start now".** The see-through screen that asks for screen capture counted as the app in front, and Roblox doesn't report again when it closes. So after Play asked for screen capture, Night-loop thought Roblox wasn't open, ran Open Roblox, and then waited for Roblox forever. That screen no longer counts.
- **Open app doesn't wait forever for an app that is already open.** Opening it again changes nothing on screen, so Android reports nothing. Now, if no app's window comes up within a few seconds, the app counts as open.
- **Sideways games are seen right.** Screen capture didn't turn with the phone: a game in landscape was squeezed into the upright picture with bars above and below, so pictures were found at the wrong size and taps went to the wrong spot. The capture now turns with the screen.
- **Big pictures are found at 100% again.** A picture bigger than 200 px is shrunk to fit, and its pixels only lined up with the screen's by chance, so text scored as low as 86% on the very screen it was picked from and Wait for picture never tapped. The screen is now lined up with the picture. Pick big pictures again once so they also remember their exact size.
- **100% Confidence works.** It means "looks the same" now, instead of every last pixel identical.
- **Match colors works on dark pictures**, like light text on a dark bar.
